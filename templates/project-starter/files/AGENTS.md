# 協作規則

本文件給所有 AI 協作者共同使用；`CLAUDE.md` 只有一行 `@AGENTS.md`。

## 底線

- 不提交金鑰、登入憑證、私人資料，或沒有授權的檔案。
- 不 force push：會蓋掉別人已經推上去的工作，改不回來。
- 不用 `--no-verify` 跳過提交前的檢查；沒通過就修到通過。
- 不用 `git add -A`：commit 前看 `git status`，只 stage 自己改過的檔案，不動別人還沒提交的修改。
- 使用者沒有明確同意就不標 ✅；沒有反對不等於同意。
- 任務說明沒寫到、做了又很難收回的步驟，停下來問使用者。
- 沒做完的功能不寫成已可使用；還沒驗證的效果寫成待驗證的目標。
- 【待填：這個專案特有、絕對不能做的事】

## 目的

- 這個專案的目的：【待填：一句話說這個專案要解決什麼問題、給誰用】
- 做成功的樣子：【待填：做成了，使用者會看到或感受到什麼】
- 最高原則：遇到任何問題先問「這樣做會不會明顯更好」；優勢明顯、代價解決得了，就應該做，工作量不是理由；好處很小的不用花很多力氣。
- 每個新提案先和「不做」比較：說出不做會壞在哪、做了哪裡明顯更好；說不出來的只記進 backlog，不寫成決定。

## 開始工作前

- 先讀 `docs/roadmap.md` 的〈現在在哪裡〉；其他文件看任務需要，照〈文件分工〉找。
- 新的 clone 先跑一次 `git config core.hooksPath .githooks`，提交前的檢查才會跑（雲端開場會自動設）。
- 開工改檔、取決定編號前，跑 `node tools/in-flight.mjs`，看開著的 PR 改到哪些檔、用了哪些編號，也看正在跑的討論串；受影響的那段等那邊合併或談定再做，其餘照做（做法見 [docs/workflow.md〈開工前先看〉](docs/workflow.md#開工前先看)）。
- 判斷這件工作在使用者的電腦還是雲端做，分法見 [docs/agents/quality.md〈本機或雲端〉](docs/agents/quality.md#本機或雲端)。
- 先載入對應的 skill：設計討論用 `discuss`、寫決定用 `decision`、寫或審程式用 `code-quality`。

## 文件分工

每類文件的用途、什麼時候進來、終點與連結寫法，見 [docs/workflow.md](docs/workflow.md)。

- 同一類資訊只維護一份，其他地方用連結。
- 狀態標示：✅ 已確認｜💬 待討論｜💡 助理提案。
- 新點子先記進 `docs/backlog.md` 的〈待處理〉，保留原意與來源。
- 文件與給使用者的回覆用【待填：文件與回覆的語言，例如繁體中文】；commit 訊息用【待填：commit 訊息的語言，例如英文】；英文名稱、程式識別字與必要的引用保留原文。

## 和使用者合作

- 能由 AI 做的就自己做，不請使用者動手；真的只有使用者能做的，才請使用者做。
- 用一般人聽得懂的話說明：少用術語，非用不可時順手解釋一句；先講結論與要使用者做的事。
- 提案時寫出和「不做」比較的結果，說出哪裡明顯更好、代價怎麼解決。
- 看到能省時間或 token 的做法就主動提，附上估計的數字（省幾分鐘、幾成 token）。
- 一個討論串只談一件事；衍生出來的事另開一串，不在原串偏題。
- 要使用者到設定頁做的步驟，給直接的連結，並寫出「做完會看到什麼」，讓使用者知道有沒有做對。

## 實作與 Git

- AI 能測的由 AI 測；請使用者測之前，先說明 AI 為什麼測不了。
- 測試或功能要延後時，照 [docs/agents/quality.md〈測試分兩類〉](docs/agents/quality.md#測試分兩類) 記進 backlog 的技術債表，不能只是沒做。
- 所有改動都開分支、走 PR，不直接推 `main`。只改文件的 PR 打開 GitHub 的自動合併，檢查的最後一關（`gate`）綠燈就由 GitHub 合併；有程式、設定、hook、workflow 或 skill 的 PR，合併前先問使用者。`main` 的保護規則還沒設好之前，不開自動合併（不然不等檢查就合併），改由 AI 看到綠燈再合併。

## 改這份檔案

- 新增規則前要過五關：① 是整個專案的重大決定（附決定編號），或同一個錯已經犯了兩三次（附實例）；② 每個 session 都用得到；③ 一句話、一個具體動作；④ 一條規則只放一處：每個 session 都要的放這裡，只有某類工作用的放 skill 或 `docs/agents/`，skill 裡全域適用的搬上來並從 skill 刪掉；⑤ 使用者明確同意。
- 每加一條，同時檢查有沒有過時或用不到、可以刪的。
