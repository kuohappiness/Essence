## 和「不做」比較（D-153、D-177）

- **不做會怎樣**：六批功能留在 `main`，孩子用不到古典詩的順序與接句、英文的打字與排序，正式 vault 也用不到「加入」與「加深」。下一次 iPhone 測試一直往上累積，出錯時更難分出是哪一批。Cards 搬進 `plugins/cards/` 的穩定基線也到不了：D-208 第 8 點要一個已部署、iPhone 驗完的版本。
- **做的代價**：一次 iPhone 實機測試，項目比 0.5.0 多（六批），加上一次升版。
- **第 1 類（上線前做足）**：會讓孩子看到沒審過的卡、少作答、讀錯紀錄或讀錯卡組的：A1～A5；第五項的發布前比較。
- **第 2 類（可以延後）**：A6 與手感 B1～B4。出錯時看得到，下一版改得回來；延後的照 D-195 寫進技術債表。

## 第二項｜iPhone 一次測完

AI 測不了的原因同 0.4.0：觸控、螢幕鍵盤、系統語音、iOS 的畫面與兩台的 iCloud 同步都要實機。做法照 0.4.0：每一步指定卡片，做完當場回報，細節由 Claude 在對話裡一次給一步。項目比較多，可以分兩段做，但兩段都用同一個待測 commit。

### 前提（Claude 在電腦做好）

- 測試 vault 裝待測 commit 的開發版，用結果檔的 `BUILD` 核對。裝之前當下看有沒有別的 session 在用測試 vault（各分支共用同一個）。
- 測試卡組（自編內容，先看 `Essence Cards/iPhone 測試/` 和各任務 Windows 實測留下的能不能直接用）：
  - 古典詩：一首有解釋的律詩、一首七言絕句、一首五言絕句（初練順序），各有接句卡與全詩順序卡。
  - 英文：文法打字卡、變化打字卡（原形還沒開始的一個、已開始的一個）、句子排序卡（長句、`the bus stop` 這種長詞塊）。
  - AI 製卡：在電腦按「加入」的兩篇（其中一篇加進已有的目標）；加深寫進檔尾的三種加深框，還沒按「加入」；一個出處有 `課外：` 的正式目標，卡組帶 `需要版本: 0.6.0`。
  - 考試範圍檔：包含有課外目標的那個單元。
- Windows 當天的 `today` 基準（同一天才有效，改天測要重跑）。
- 同步要等：電腦的 iCloud 約每小時 :17 才下載（0.4.0 A13），iPhone 到電腦最慢量過 50 分鐘以上（0.4.0 A1）。等待由 Claude 看檔案到了沒。
