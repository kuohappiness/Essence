# Essence｜轉錄稿格式

更新：2026-11-20｜狀態：✅ 定稿（[D-092](decisions.md#d-092-出題語法定稿正式規範)、[D-080](decisions.md#d-080-轉錄稿的錨點與出處的寫法)）｜2026-11-20 從 Cards 的出題語法 §1 搬到最上層（[D-208](decisions.md#d-208-三個外掛在同一個-repo-開發每個外掛有自己的資料夾) 第 6 點，第二步 B），內容不變

Capture 寫、Cards 讀的轉錄稿格式，三個外掛共用這一份；改的時候兩邊都要能讀（分派表把這份登錄成共用規格，改它會跑 Capture 的完整檢查與 Cards 讀它的測試）。Cards 自己的格式見 [Cards 的出題語法與資料格式](../plugins/cards/docs/syntax.md)。節號照搬來之前的 §1，舊連結 `syntax.md#1-轉錄稿` 在原處留了一行轉到這裡。

狀態標示：✅ 已確認｜💬 待討論｜💡 助理提案

## 1. 轉錄稿

Capture 把課本、講義忠實轉錄成的 Markdown，是兩個外掛唯一的接點（[D-076](decisions.md#d-076-capture-是知識入口教材轉錄成教材庫)、[D-080](decisions.md#d-080-轉錄稿的錨點與出處的寫法)）。教材庫是共用、唯讀的：Cards 只讀，不寫進任何個人的回饋（[D-093](decisions.md#d-093-教材庫共用個人回饋留在錯題本)）。

```markdown
---
來源類型: 課本
來源: 國二上自然 第二章.pdf
出版社: 翰林
版次: 114 學年度
建立日期: 2026-10-13
---

# 2-2 水溶液

p.43 ^p43

## 1 溶液

糖放進水裡，攪拌後看不見了，形成均勻的**糖水**。……

p.44 ^p44

## 2 擴散現象

……

![[國二上自然 2-2 圖2-14.png]]
*圖 2-14 黑糖在水中慢慢散開* ^fig2-14

> [!補充] 知識快遞
> ……

| 溫度（°C） | 20 | 60 |
|---|---|---|
| …… | …… | …… |

^tab2-1

**例題 2-3** ^ex2-3

……
```

**屬性**：

| 屬性 | 內容 | 必填 |
|---|---|---|
| 來源類型 | 例如 課本、講義、圖片 | 必填。Cards 只看有沒有這個屬性：有就不當成卡組，放在哪裡都一樣（D-088 補充）。有這個屬性的就是教材：針對這次考試範圍的文件，不限課本；名稱分學校的 `課本`、`學校講義`（老師的講義、學習單、習作）與校外的 `補習班講義`、`影片筆記`、`其他教材`；學校、校外的分法只給 AI 看（教材之間說法不一致時學校的優先），程式不靠它排程；寫了別的字照樣算教材、不提示（[D-152](decisions.md#d-152-教材是針對考試範圍的文件補充筆記另外放)）。家長自己寫的補習班筆記要當教材，在屬性加一行 `來源類型: 補習班講義` |
| 來源 | 原檔名或網址（[D-031](decisions.md#d-031-capture-定位與交接約定修訂)） | 必填 |
| 出版社、版次 | 例如 `翰林`、`114 學年度`；從檔名猜，家長可以改（D-080 補充） | 課本才寫 |
| 建立日期 | 轉錄的日期，用來判斷來源有沒有更新 | 必填 |

Capture 不寫年級、科目這類學生專用的資訊（D-031）；冊別與科目只出現在檔名，因為它們是課本本身的名稱。

**錨點**（只需要在同一篇轉錄稿裡不重複，連結一定帶著筆記名稱）：

| 錨點 | 寫法 | 例子 |
|---|---|---|
| 頁碼 | 看得到的一小行 `p.頁碼 ^p頁碼`，前後各空一行；頁面上看不到頁碼時寫 PDF 頁序 | `p.44 ^p44`；`PDF 第 12 頁 ^pdf12` |
| 有編號的圖 | 圖檔與圖說寫在同一段：圖檔一行，下一行是斜體圖說，ID 在圖說最後 | 圖 2-14 → `^fig2-14` |
| 子圖 | 同一個圖號分成 A、B 幾張時各截一張，ID 加小寫字母（[D-094](decisions.md#d-094-t4-第四輪試用後的修正)） | 圖 2-13 A → `^fig2-13a` |
| 沒有編號的圖 | ID 用頁碼加這一頁的第幾張 | `^p43-fig1` |
| 有編號的表 | Markdown 表格；表格之後空一行，再單獨一行寫 ID，後面也空一行（Obsidian 對表格區塊 ID 的規定） | 表 2-1 → `^tab2-1` |
| 例題 | 例題的標題寫成粗體段落，ID 在同一行最後（Obsidian 的標題不能加區塊 ID） | 例題 2-3 → `^ex2-3` |
| 段落標題 | 照課本的層級用 `#`、`##`、`###`；Obsidian 本來就能連結，不另加 ID | `## 2 擴散現象` |

**其他規則**：

- 忠實轉錄，不摘要；粗體照原樣；公式用 LaTeX，例如 `$\text{g/cm}^3$`。
- 圖檔名含冊別、科目、單元與圖號：`國二上自然 2-2 圖2-14.png`，子圖加大寫字母：`國二上自然 2-2 圖2-13A.png`；沒有編號的用錨點，例如 `國二上自然 2-2 p43-fig1.png`。只用來裝飾的圖不截。
- 表格寫不成 Markdown 表格的（合併儲存格太多），當成圖處理。
- 「補充閱讀」這類方框寫成引言框，例如 `> [!補充] 知識快遞`；教師用書給老師看的內容寫成 `> [!教師註記]`，製卡時只當判斷重點的線索，不當課本內容出題。
- 課本自己列出的學習目標或學習重點（例如每節開頭的方框）照原文寫成引言框 `> [!學習目標]`；製卡時當對照表，檢查有沒有漏、判斷重要性（[D-101](decisions.md#d-101-學習目標的數量由內容決定)）。
- 看不清楚的字寫 `[?]`，後面括號寫最可能的字，例如 `[?]（溶）`，給家長檢查；為了讓圖表看得懂、非補不可的說明，標 `[AI 補充]`。
