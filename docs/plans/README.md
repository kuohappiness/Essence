# Essence｜細項規畫（plans）

還在規畫的細節放這裡，一個主題一份、不按日期重開；外掛專用的放外掛的 `docs/plans/`。plans 什麼時候進來、狀態行怎麼寫、定案後怎麼轉出，以及每類文件放在哪裡、怎麼互相連，都見[工作流程規範](../agents/workflow.md#plans)（[D-214](../decisions.md#d-214-工作流程一件事一個現在位置反方向由工具算) 第 1 點）；資料夾的分法見 [architecture.md〈每一類放哪裡〉](../architecture.md#每一類放哪裡)。工作只分「v1 需要做的任務」與「第二階段想做的事」，統一入口在 [backlog](../backlog.md)（[D-130](../decisions.md#d-130-任務分成-v1-與第二階段)）。

「第二階段」是下一階段候選清單，不承諾單一版本全部完成。舊文件的「增強版」「v2」「v2 之後」「未來」都由這個入口追蹤；歷史原文可保留，不另設交付級別。已確認方向、使用者提議、助理提案與條件式候選仍要分清楚。
