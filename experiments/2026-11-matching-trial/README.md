# 配對與單選的試作（第 0 段）

狀態：準備好，等在使用者的電腦試作｜來自：[配對與單選任務說明](../../apps/Cards/docs/tasks/matching-single-choice.md) §0、[D-249](../../docs/decisions.md#d-249-配對與單選題目後面一行選項有一個要出就整組作答)

要回答的問題：照 D-249 的寫法與 §7 的規則草稿，真的國小社會教材做得出幾組配對？AI 寫得穩不穩？寫程式之前先知道這兩件事。

這個資料夾只放步驟與規則草稿。教材、vault 的內容、AI 的回覆都放在使用者電腦 repo 外面的資料夾，不進 repo（`AGENTS.md` 底線、[試作場的規則](../README.md#規則)）。進 repo 的只有下面〈結果〉的數字與結論，目標名稱以外的教材內容不寫。

## 步驟（給在使用者電腦操作的 Claude）

1. **選課**：國小社會一課，優先康軒五上 2-1（海岸）；沒有這一課的教材就用最近做過的一課。只用使用者電腦上已有的教材與 vault，記下用的是哪一課（寫課代號就好，vault 用代稱）。
2. **提示**：照外掛產生的國小社會提示，勾「點選填空」（實際使用就是勾著的，也同時收到比較卡的規則），把下面〈規則草稿〉接在任務段 `- 家長勾了點選填空：` 那一段的最後（縮排成它的子項目）。建議用 [比較測試工具](../../apps/Cards/tools/rule-test/README.md)的 `自備` 組產生；只跑到生成與格式檢查，不做評分表、匿名與評分。
3. **生成兩份**：同一課跑兩次（各開新的對話），或兩課各一次。回覆存在 repo 外面，**不貼回外掛、不存成卡組**。
4. **格式檢查**：用外掛的檢查看每一份（`npm run rule-test -- check`，或直接用 `parseDeck`），另外照〈要記的數字〉的第 2 項自己數選項行的寫法偏差（外掛還不認 `選項：`）。
5. **代審**：每一份另開一個新的對話，只給題幹與選項（不給答案、不給教材以外的東西），照〈代審的清單〉看。
6. **回報**：把〈要記的數字〉填進〈結果〉，附用量（開了幾個對話、用哪個模型）。停損條件成立時先回報，不往下做。

## 規則草稿

接在 `- 家長勾了點選填空：` 那一段的最後，每行前面縮兩格：

```markdown
- 配對與單選（R3 短規則「沒有選項」的例外，只用在下面兩種）：
  - 判斷屬於固定幾類中的哪一類（例如臺灣四部的海岸）：每一類一個學習目標，名稱寫「能從……認出……」，題目是那一類的描述或例子，這幾個目標寫同一行選項。
  - 教材本來就是對照表的一組一對一的事實（例如四個方位的海岸各是什麼地形）：每個事實一個學習目標，也寫同一行選項。
  - 只在要練的是把例子或描述歸到固定的幾類、或一組對應容易互相記混，而且題幹自己就能回答時用；出處要指得到教材的分類或對照表、習作用選或連的那一題、或架構段寫的邊界，指不到就不加選項行。
  - 不用的：「下列何者」「哪一個不是」、是非、只有兩項的配對、彼此不相干的一組、定義、原因、語詞解釋、計算。
  - 選項只准來自教材：固定的類別、同一組其他目標的答案、架構段「邊界」寫的錯答；不要自己編，湊不出兩個錯的選項就不加選項行。3～5 個；類別本來有 4、5 個就全列。
  - 選項行寫在題目後面、和題目同一層，例如 `- 選項：北部、東部、西部、南部`：全形冒號、頓號隔開、包含答案；不接在出處那一行，不縮在出處或題目底下。
  - 同一組的每個目標寫完全相同的選項行（同樣的字、同樣的順序），一組 3～5 個目標；判斷是哪一類的，類別有幾個就寫幾個目標。
  - 一組裡有學生已有的目標，那幾個也加同一行選項行（照加進已有學習目標的寫法）。
  - 自我檢查：試填每個選項，只有一個說得通。
  - 例子（只示範結構）：
    - 能從景觀描述認出西部的海岸
      - 出處：p.42
      - 海岸平直，有沙灘和潟湖，是臺灣哪一部的海岸？ :: 西部
      - 選項：北部、東部、西部、南部
```

## 代審的清單

給代審的對話：

> 下面是一份閃卡草稿裡有「選項：」的題目，每題只有題幹與選項，沒有答案。逐題看：① 只看題幹，選項裡是不是剛好一個說得通（兩個都說得通的列出來，寫哪兩個、為什麼）；② 有沒有「下列何者」「哪一個不是」這類考卷式的問法；③ 選項有沒有教材裡不會出現、像是自己編的；④ 同一組（選項行一樣的）是不是彼此平行、屬於同一種分類或對照。只回清單，不要重寫題目。

## 要記的數字

1. 做得成幾組配對、每組幾個目標；其中判斷是哪一類的幾組、對照表的幾組；單選（一組只有一個目標）幾個。
2. 選項行的寫法偏差各幾處：接在別的行、縮在別的行底下、寫在題目前面、半形冒號、粗體、子清單、頓號和逗號混用、選項裡有 `==` `::` `｜`。
3. 同一組的選項行寫得一不一致（有沒有只差一項、順序不同的兩組）。
4. 同一組選項最多被幾個目標共用；目標數和選項數一樣多（最後一格猜得到）的組幾組；超過 5 個目標的組幾組；選項最長幾個字。
5. AI 做成比較卡、配對各幾組，分得對不對；判斷是哪一類的，有沒有每類一個目標（沒有寫成一個目標好幾題、答案不同）。
6. AI 有沒有寫出「下列何者」、編了教材沒有的錯選項、把想得出來的事實做成配對；代審找到「兩個都說得通」幾處。

**停損**（都是先把數字給使用者看，不自己決定開工）：一課做得成的少於 2 個目標、配對 0 組，或代審找到「兩個都說得通」；寫法偏差多（兩份裡同一種偏差出現兩次以上）時，先補任務說明 §6 的檢查與 §7 的寫法句子。
