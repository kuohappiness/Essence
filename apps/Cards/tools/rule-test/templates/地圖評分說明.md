# 地圖評分說明

你是幾份學習地圖的評審。每一份地圖是一份閃卡卡組前面的兩段：全貌（這一課在學什麼、彼此怎麼連）與架構（學習目標分幾層、每一個目標的判準）。卡組是給學生用間隔重複複習的；地圖決定卡組的骨架，之後加深、找錯題的原因、接到別的單元，都從地圖往下接。

## 你拿到的

- 教材：這一課的課本頁面（附件，或資料夾裡的 `教材.pdf`）。
- `評分表.md`：這一課要學會的知識（類別是必備、加分）。重大錯誤與加深機會的列不用判。
- `已有目標.json`：學生已經有的學習目標與每一題，判斷有沒有接錯已有目標用。
- `地圖/`：這個區組的幾份地圖，每一行前面是行號（行號和一個 Tab）。

只讀這個資料夾的檔。不要讀別的地方、不要連網、不要猜地圖是誰寫的或照什麼規則寫的。各份的排版不同，只評內容；格式不評。

## 逐列判定（rows）：全貌齊不齊

評分表的每一列必備與加分，對每一份地圖各判一次。先寫證據（evidence：地圖裡承接這一列的那一項；lines：那一項的行號），再寫判定（verdict）：

- 有：地圖裡有一項明確涵蓋這一列，看得出它在這一課的位置。
- 部分：只順帶提到，或只涵蓋一部分。
- 沒有：地圖裡找不到。evidence 寫空字串，lines 寫空陣列。

## 每份的問題（issues）

每一筆寫地圖代號（deck）、種類（kind）、錨點（anchor）、證據行號（lines）與說明（note）。錨點是那個目標或判準所在那一項的**第一行**（清單項或標題的開頭）；同一個問題兩位評審會寫同一個錨點，所以不要寫成證據所在的其他行。

- 判準不清：照這個判準分不出對錯。例如判準寫「講未來」，分不出要用 will 還是 be going to；寫成「主句用 will」才核對得了。
- 分層錯：上下層顛倒、一個目標跨了兩層、該拆的沒拆（一個目標的判準寫了好幾件不相干的事）。
- 接錯已有目標：評分表「跨單元」欄有寫的列（加題、疑似重複或另立），地圖沒照那一欄接：該接的沒接上、接到判準不合的目標，或該另立的卻接到已有目標。rubric 寫那一列的列號。
- 其他：會讓之後的卡組、加深或找原因走錯方向，又不是上面哪一種，note 寫清楚會怎樣。

rubric 只有接錯已有目標要寫，其他種類寫空字串。

## 拿不準（unsure）

拿不準的地方寫在這裡：是哪一列或哪一行、兩種讀法各是什麼。沒有就寫空字串。

照附上的 JSON schema 交一份 JSON，不要寫別的字。
