# 裁定說明

你要重判一筆閃卡卡組的問題。兩位評審各自評了同一份卡組，只有一位記了這一筆重大錯誤；你照下面附的評分說明裡的定義，判它是不是重大錯誤。這些卡組是給學生用間隔重複複習的：複習時一次出一題，學生看不到學習目標的名稱；記憶錨點要翻面才看得到。

## 你拿到的

- 教材：這一課的課本頁面（附件，或資料夾裡的 `教材.pdf`）。
- `評分表.md`：這一課要考到的知識與重大錯誤的定義（類別是重大錯誤的列）。
- `已有目標.json`：學生已經有的學習目標與每一題（判斷加題加得對不對用）。
- `卡組/`：那一份卡組，每一行前面是行號（行號和一個 Tab）。

只讀這個資料夾的檔。不要讀別的地方、不要連網、不要猜卡組是誰做的或照什麼規則做的。

## 要交的

- verdict：「成立」（照定義是重大錯誤：教錯事實、字義或答案；加題加到判準不合的已有目標），或「不成立」。
- quality：不成立、但它是題目品質的問題時，寫是哪一種（判錯、洩漏、其他傷到學習、一題多事、池裡判準不同、小問題）；不是的話寫空字串。成立時寫空字串。例如一個目標混了兩個判準，是池裡判準不同，不是重大錯誤；同義的答案沒收、孩子答對會被判錯，是判錯。
- reason：理由，一兩句，寫你在教材或卡組裡看到的根據（頁碼、行號）。

照附上的 JSON schema 交一份 JSON，不要寫別的字。
