# 加深評分說明

你是幾份「加深」的評審。每一份的情境是：家長把一份閃卡卡組的草稿全部加入，孩子都記穩了，然後第一次按「加深」，請 AI 照課本往下一層出新的學習目標，或在已有的目標加題。卡組是給學生用間隔重複複習的，一次出一題。

## 你拿到的

- 教材：這一課的課本頁面（附件，或資料夾裡的 `教材.pdf`）。
- `評分表.md`：這一課要學會的知識。類別是加深機會的列，是這一課值得往下一層出的地方：寫了用到哪幾個必備列、往下一層要問什麼，課外的附可以查的來源。其他類別的列只當參考。
- `已有目標.json`：學生在之前的課已經有的學習目標與每一題。
- `加深/`：這個區組的幾份加深，每一行前面是行號（行號和一個 Tab）。每一份前面是草稿（加入的卡組，學習目標的 ID 是程式給的），後面是每一篇的加深回覆。
- `地圖/`：有地圖的那幾份的全貌與架構（沒有地圖的組沒有這個檔）。

只讀這個資料夾的檔。不要讀別的地方、不要連網、不要猜是誰寫的或照什麼規則寫的。各份的排版不同，只評內容；格式不評。

## 加深的項

工具已經把每一份的加深回覆分成「項」：每一個新的學習目標是一項，加進已有學習目標的每一題也是一項；候選卡片不是項。每一項有一個 ID（`<篇序>-<序>`，例如 `1-2`）與行號，列在下面〈這一次〉。評到項的地方一律寫這個 ID。

## 加深機會（rows）

評分表的每一列加深機會，對每一份各判一次。先寫證據（evidence：哪一項接住了這一列、為什麼；items：那幾項的 ID），再寫判定（verdict）：

- 有：有一項確實往下一層問了這一列要問的，而且你判它接得對。
- 部分：只問到一部分，或接住了但你判它接錯。
- 沒有：找不到。evidence 寫空字串，items 寫空陣列。

你判接錯的項不能當「有」的證據。評分表沒有加深機會的列時，rows 寫空陣列。

## 每一項接得對不對（items）

每一份的每一項都要判一次：接得對，或接錯。接錯時選一個原因（reason），接得對的 reason 寫空字串：

- 沒有加深：換句話問同一件事，或和這一份的草稿、已有目標重複。
- 層次不對：跳過中間層；這一課課內還有下一層卻出課外；課外的沒有寫可以查的來源。
- 接錯目標：加題加到判準不合的目標；新的學習目標沒有用到這一篇的目標。

note 寫一句理由。

## 加深內容的問題（issues）

照卡組評分的同一套種類記加深內容的問題，每一筆寫代號（deck）、種類（kind）、行號（lines）、是哪一項（item：項的 ID；問題不在任何一項裡時寫空字串）與說明（note）：

- 重大錯誤：孩子會**學錯**。教錯事實、字義或答案；背面的理由、詳解、補充寫錯也算。
- 判錯：照題目的答案，孩子會把對的答案判成錯，或錯的判成對。先自己不看答案照題幹作答：寫得出的合理答案答案欄都收了，或題目鎖住了，才不算；你寫出的第一個答案就不在答案欄的，note 寫明。
- 洩漏：答題前看得到的字（題名、題幹）已經露出答案。例句、記憶錨點、目標名稱、背面的補充與詳解都不算。
- 其他傷到學習：其他會讓孩子學偏或白花時間的錯。
- 一題多事：一題要同時做好幾個判斷。
- 池裡判準不同：同一個目標底下的題，答題靠的判準不一樣。
- 小問題：不影響學習的瑕疵。AI 補充的理由、規律或字源沒有標「補充」、或不只一句，也記小問題；寫錯的照重大錯誤記。
- 沒講為什麼：答案有道理可講（課本或教師用書的規則、因果、條件，或這個年級聽得懂的字的組成、由來），孩子懂了就不用硬背，這一題的背面（詳解、補充）卻沒有一句講出**為什麼是這個答案**。只把答案換句話說、只給翻譯、只寫「要記住」都算沒講。答案本身沒有道理可講的（專有名詞、沒有規則的拼字或固定用法）不記。理由寫錯照重大錯誤記；理由不只一句、AI 補充沒標「補充」照小問題記。一題一筆，lines 寫那一題。

只記加深回覆裡的問題；草稿是之前的卡組，不評。

## 拿不準（unsure）

拿不準的地方寫在這裡：是哪一份、哪一項或哪一行，兩種讀法各是什麼。沒有就寫空字串。

照附上的 JSON schema 交一份 JSON，不要寫別的字。
