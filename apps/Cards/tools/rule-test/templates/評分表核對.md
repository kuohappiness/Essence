# 評分表核對

另一位寫了一課課本的評分表（`評分表.md`）。之後會有幾份閃卡卡組照這份表評分。你逐列對照教材核對，找出要改的地方。

## 你拿到的

- 教材：這一課的課本頁面（附件，或資料夾裡的 `教材.pdf`）。
- `評分表.md`：要核對的評分表（格式寫在下面）。
- `已有目標.json`：學生之前的課已經有的學習目標，核對「跨單元」那一欄用。

只讀這個資料夾的檔。不要讀別的地方、不要連網。

## 評分表的格式

- 類別：必備（學生一定要會的）、加分（學了更好的）、重大錯誤（會教錯的地方）、加深機會（記穩了這一課之後值得往下一層出的地方，判準寫 `用到 R1、R3：往下一層要問什麼`，課外的附可以查的來源）。
- 跨單元：`加題 <ID>`、`另立`、`疑似重複 <ID>` 或空著。
- 依據（只有必備寫）：`正文`（課本正文寫出的）、`提問`（課本提問或習作考到的），或課本沒明列而加成必備的 `後面要靠它`、`容易混`、`規律`。

## 要找的

- 每一列：教材上真的有嗎、頁碼對嗎、類別合理嗎（必備與加分分得對嗎）、判準寫得夠清楚嗎、等價做法有沒有漏、跨單元的去向對嗎、依據對嗎（寫正文的真的在正文；課本沒明列的必備，說得出是那三種的哪一種，說不出的改成加分）。加深機會：真的是往下一層（不是換句話問同一件事）、用到的必備對嗎、課外的來源查得到嗎、每頁最多 3 列。
- 漏掉的：教材上該考、表上沒有的知識；課本或教師用書寫出的規律、因果沒有自己一列必備；容易教錯、表上沒列的重大錯誤。
- 重複的：兩列在考同一件事。

## 要交的

一條一個意見，寫成清單：開頭寫列號（漏掉的寫「新增」），再寫要怎麼改、為什麼（附頁碼）。沒有意見的列不用寫。最後一行寫「共 N 條」。
