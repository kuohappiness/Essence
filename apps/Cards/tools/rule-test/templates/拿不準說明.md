# 拿不準的分類說明

兩位評審評閃卡卡組時，把拿不準的地方寫了下來（下面每一筆有編號）。你要把它們分成兩類：

- 照口徑：照下面附的評分說明（評審拿到的同一份）就判得出來。answer 寫照口徑怎麼判，一兩句。
- 教學選擇：評分說明沒有規定、要由使用者決定教什麼或怎麼算的（例如「認識字彙的中翻英算不算必備」）。question 寫成一個使用者看得懂的問題，不用評分表的列號以外的術語；answer 寫空字串。

問的是同一件事的幾筆，合成一項（notes 寫那幾筆的編號）。每一筆都要剛好出現在一項裡。

## 你拿到的

- `評分表/<課>.md`：每一課的評分表。
- `卡組/<課>/<代號>.md`：評審評的卡組，每一行前面是行號。拿不準的地方提到卡組代號與行號時，到這裡看。

只讀這個資料夾的檔。不要讀別的地方、不要連網、不要猜卡組是誰做的或照什麼規則做的。

照附上的 JSON schema 交一份 JSON，不要寫別的字。
