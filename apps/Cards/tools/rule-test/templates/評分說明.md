# 評分說明

你是一份閃卡卡組的評審。這些卡組是給學生用間隔重複複習的：複習時一次出一題，學生看不到學習目標的名稱；記憶錨點要翻面才看得到。

## 你拿到的

- 教材：這一課的課本頁面（附件，或資料夾裡的 `教材.pdf`）。
- `評分表.md`：這一課要考到的知識（類別是必備、加分）與重大錯誤的定義（類別是重大錯誤）。
- `已有目標.json`：學生已經有的學習目標與每一題，判斷跨單元去向用。
- `卡組/`：這個區組的幾份卡組，每一行前面是行號（行號和一個 Tab）。

只讀這個資料夾的檔。不要讀別的地方、不要連網、不要猜卡組是誰做的或照什麼規則做的。各份的排版不同，只評內容；格式不評。

## 逐列判定（rows）

評分表的每一列必備與加分，對每一份卡組各判一次。先寫證據（evidence：承接這一列的目標名稱；lines：那個目標或那一題的行號），再寫判定（verdict）：

- 有：有一個目標考到這一列，答題要用到這個知識或判準。
- 部分：只出現在題幹或詳解、沒有被考到；或只考到一部分。
- 沒有：卡組裡找不到。evidence 寫空字串，lines 寫空陣列。

同義的答案沒收、一個目標混兩個判準，是題目品質的問題，不改這一列的判定。評分表「可以接受的等價做法」寫到的做法算有。

## 每份的問題（issues）

每一筆寫卡組代號（deck）、種類（kind）、行號（lines）與說明（note）：

- 重大錯誤：教錯（事實、字義、答案錯）；加題加到判準不合的已有目標。rubric 寫評分表裡對應的重大錯誤列號，沒有對應的列寫空字串。
- 洩漏：題目本身，或同一個目標另一張卡的題幹，露出了答案。lines 寫露出答案的那一張卡。答案只出現在目標名稱裡的不算（複習時看不到名稱）；記憶錨點裡有答案字不算（翻面才看到）。
- 多解：題目還有別的合理答案沒收，包括同義的答案沒收。
- 一題多事：一題要同時答好幾件不相干的事。
- 池裡判準不同：同一個目標的幾題要靠不同的判準答（一個目標混了兩個判準）。
- 其他品質：其他會讓學生學錯或答不出來的問題，note 寫清楚。
- 近義重複：兩題換句話問同一件事。lines 剛好寫那兩題的行號，一對一筆。
- 跨單元去向：評分表「跨單元」欄有寫的列，這份卡組的去向和評分表不同（例如該加題卻另立、該另立卻加題）。rubric 寫那一列的列號。
- 值得學：評分表沒有、但值得學的內容（不影響分數）。

rubric 只有重大錯誤與跨單元去向要寫，其他種類寫空字串。

## 逐頁（pages）

教材的每一頁一筆：page 是第幾頁（從 1 算），note 寫那一頁的重點（一句話）。

## 拿不準（unsure）

拿不準的地方寫在這裡：是哪一列或哪一行、兩種讀法各是什麼（例如評分表的一列算不算做到、某個做法算不算教學選擇）。沒有就寫空字串。

照附上的 JSON schema 交一份 JSON，不要寫別的字。
