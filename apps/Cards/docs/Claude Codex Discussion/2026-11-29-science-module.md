- **考卷已經有了**：使用者 2026-10-21 給過國二上自然的第一次段考（4 張照片、40 題，第 1、2 章）與第 2 章的教師備課用書。考卷已經轉錄，Claude 與 Codex 各自逐題標了「答對需要的知識與判斷」並凍結，兩輪生成與盲評的結果都在測試 vault 的「學習目標架構」資料夾（不進 repo）。使用者 2026-11-29 確認：這次說的就是這一份（115 學年度上學期國二上自然），孩子沒有用過自然卡，所以這份考卷能看的是「規則做出的卡接不接得住段考考的知識」，看不到孩子自己的複習；下一次段考考第 3、4 章。
- **那份考卷找到的缺口**：
  - 第一輪（2-1、2-2，[第一輪結果 §4](<2026-10-21-learning-objective-architecture.md#4-三種結果>)）：缺口最多的原因是判準太寬，判準沒有要求考題真正在考的那個判斷。兩家都指出的例子：「分離方法屬於物理變化」（第 2、29、31 題）五份架構都沒有判準要求；「溫度升高、固體溶解度通常變大」有三份架構明寫不推論方向。另有轉錄把「給學生」欄標成教師註記、只寫在圖說的內容被漏掉（[§6](<2026-10-21-learning-objective-architecture.md#6-教材輸入的發現和選哪個模型無關>)）。
  - 第二輪（1-3，[第二輪結果 §3、§4](<2026-10-21-learning-objective-architecture.md#4-九份都有的缺口>)）：R3 贏在把「在圖上比較陡度」放在第 ① 層、把「水的密度」列成目標；九份都有的缺口是公式只要求寫出，沒有要學生由其中兩個量求第三個（第 16、32 題），以及「容量」的定義只做成單位換算。
- **這份考卷已經調過規則**：第一輪的缺口寫進了 R3 的判斷邊界，第二輪用 1-3 選出 R3。照 Codex 回應第三輪規劃 §5，從舊考題歸出通則可以，但那份考卷之後只能當開發材料（回歸案例），不能再當獨立驗證。

## 2. 模組 v0.1 怎麼寫成的

💡 草稿在 [`card-rules/next/science.md`](../card-rules/next/science.md)。寫法照國小社會模組：只寫這一科怎麼套用，不重複核心與製作模組（[R3 重整的分法](../backlog.md#其他待決)）。

### 2-1 自然預設 v0.5 每一條的去向

| v0.5 的條文 | 去向 | 理由 |
|---|---|---|
| 知識類型的表（定義、因果、比較、順序、實驗、公式與單位、圖表） | 留在模組〈知識類型怎麼問〉，只留問法；實驗、圖表另寫一節 | 問法是這一科的；分類本身核心已經用「一個目標一項能力」處理 |
| 規則 1 理解型至少三分之一 | 拿掉 | 核心前提 1「數量由內容決定，不湊數」；三層從核心判斷倒推，「為什麼」已經在〈每課一定要有〉第 2 類。優化三層串也記了換三層時拿掉這項檢查（B13） |
| 規則 2 生活例子在教材範圍內、同一個原理同一池 | 留在〈比較與分類〉最後一條 | 同池在核心前提 2 已有，這裡只留一行提醒自然最常見的情形 |
| 規則 3 計算題不做成閃卡、例題的觀念一定要出一題（D-094） | 留在〈公式與計算〉，備註的「建議另外練習」改成架構的「需要其他練習」 | 核心 v0.3 起備註不寫建議另外練習（規則循環第一輪教學選擇 4）；製作模組已有〈例題的觀念〉，這裡只指過去 |
| 規則 4 用語跟課本一致（質量和重量） | 留在〈寫給孩子〉 | 核心前提 6 已有「術語和教材一致」，自然最容易錯的是日常說法，留一個例子 |
| 自我檢查兩項 | 併進〈交出前檢查（自然）〉 | |
| 錯題處理的表 | 檔尾標記後面，製作時不送 | 和英文模組一樣，錯題分析做成功能時再改寫 |

### 2-2 從段考缺口歸出的通用規則

每一條都不是為那一題寫的：例子換成別的單元（速率），條文要在沒有密度、溶解度的單元也成立（[製卡規則只寫通用的](../../../../docs/decisions.md#d-235-製卡規則只寫通用的國語照建教師用書標出的修辭與句型)）。

1. **公式用到的每個求法都要練到**（第 16、32 題）：一個公式一個目標，池裡第一題問公式，再加教材例題、習題用到的每一個求法各一題「已知……求……，怎麼列式」。
   - 不做：九份都漏，換一個模型也漏；學生記得公式卻不會倒過來用，段考的計算題第一步就卡住。
   - 代價：池變大（一個公式多 1～2 題）。照 Codex 的提醒（第三輪規劃 §5）不把每個求法拆成目標、不出教材沒用到的變形，排程不會變多。
2. **關係要說出方向**（「溫度升高、固體溶解度通常變大」）：判準與答案寫出方向和條件，只答「會影響」不算會。
   - 不做：三份架構明寫不推論方向，卡就只考「有關」，考卷問的是怎麼變。
   - 代價：幾乎沒有；核心範例（高溫對酵素）本來就這樣寫，這裡把它寫成自然的通則。
3. **讀圖在第 ① 層**（在圖上比較陡度）：教材要學生讀出的關係不留到加深，判準寫出從圖上的什麼判斷什麼。
   - 不做：製作模組 v0.3 已經寫「教材寫出來的都是第 ① 層」，可能已經夠；但第二輪只有 R3 做到，R0～R2 都把它放到第 ②。多一句明講，代價很小。
4. **定義的名詞與教材的數值**（容量、水的密度）：〈每課一定要有〉第 1、3 類。粗體與「稱為」的名詞要有題目考到（不一定自己一個目標）；教材寫出、後面要用的數值另立或放進用到它的池。
   - 代價：可能多出幾個定義的目標。照 Codex 的提醒，不逐句製卡：要的是理解時不可缺、學生要自己說出的區別。
5. **分類套到別處的例子**（分離方法屬於物理變化）：教材在別處講到、又寫了它屬於哪一類的操作或現象，加進那一類的池；只有兩類時題目要學生說出依據，不出只答一類的題（核心前提 3 的二選一）。
   - 不做：三題的錯誤選項都在這裡，五份都沒有。
   - 代價：分類的池多幾題；同一池，不多排程。

沒有寫進模組的：「給學生」欄被標成教師註記是轉錄的問題（[transcript.md](../../../../docs/transcript.md)，第二輪已修）；只在圖說的內容，製作模組〈只在圖說、插圖裡的人物對話、旁欄出現的內容〉已經處理；排水法的兩張洩漏卡，核心前提 3 已經處理。

### 2-3 給優化三層串的觀察（不在這裡改）

- 核心〈卡組的寫法〉的範例把「知識快遞」放進候選卡片，理由寫「段考不一定考」。第一輪的第 5 題考的就是 2-2 知識快遞裡的「水溶液不論水量都稱水為溶劑」。製作模組的旁欄規則（容易和別的搞混的做成目標）照理會把它做成目標，但範例可能讓模型把知識快遞一律放進候選。一題是一個樣本，只提給優化三層串參考。

## 3. 驗證怎麼做（提案）

💡 下一次自然段考是規則沒看過的考卷，用它比三層（核心 v0.7＋製作 v0.3＋自然 v0.1，送測時凍結）和外掛現行的 R3 第二輪：

1. **材料**：那次段考範圍的課本或教師備課用書、考卷照片。轉錄照 `transcript.md`；考卷照 `experiments/t4/arch/考題轉錄.md` 轉錄。
2. **先標再生成**：照 `experiments/t4/arch/考題標註.md` 逐題標「答對需要的知識與判斷」，兩家各自標、凍結後才生成。寫規則的人在凍結前不看那次的考卷與教材，規則也不再照它改。
3. **生成**：兩組同一個模型、同樣的推理設定，每一節各一份；跑前先報 token 用量問使用者。
4. **評**：照[驗證卡片評估機制](2026-11-27-validate-evaluation.md) §8-6 的評分表（必備覆蓋、重大錯誤、判錯、洩漏、孩子的時間），覆蓋以段考標註為準；計算與應用題不要求做成卡，看背後的觀念有沒有接住。
5. **讀法**：照 D-251 的方向，三層沒有明顯比較差就建議自然改用三層；結果請使用者決定。

不做（只靠舊考卷）：那份考卷調過規則，比出來的結果偏向照它寫的規則，不能判斷三層是不是真的比較好。等下一次段考的代價是時間，模組可以先寫好。
