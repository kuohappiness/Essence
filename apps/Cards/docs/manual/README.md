# Essence Cards 使用說明書（正本）

這個資料夾是說明書的正本，一節一個 Markdown 檔。規畫、章節表與樣式見[說明書規畫](../plans/manual.md)。

- **現在有的**：只有試寫的一節[〈自己寫卡組〉](make/write-your-own-deck.md)（使用者 2026-11-22 要求先寫這一節）。其他節等 v1 的功能都合併、畫面不再改才寫（[規畫第 5 節](../plans/manual.md#5-什麼時候開始)）。
- **還沒有的**：產生網站的建置。在那之前，正本只在 repo 裡讀。
- **資料夾對應網址**：這個資料夾對應網站的 `/cards/`，底下照章節表的部分開資料夾（`make/` 是「製卡」）；檔名就是那一節固定的網址，定了不改。

## 寫法

- **每一節保持最新狀態**：功能改了就直接改寫那一節，不在下面加帶日期的補充；為什麼改、什麼時候改，留在決策紀錄與 git 的歷史（[D-221](../../../../docs/decisions.md#d-221-cards-使用說明書形式版面章節與維護) 第 6 點）。功能任務改到已寫好的節時，同一個 PR 一起改（同一條第 8 點）。
- **第一行**寫適合誰看、對應的版本、最後查核的日期；不寫「給家長」「給學生」。
- **每一句都對過最新的決定與程式才寫**；沒做完的功能不寫成可以用。還會變、先不寫的，列在那一節最後的「還沒寫進來的」。
- **用詞照畫面上的字**。
- **截圖**：圖檔放在那一節旁邊的 `img/`，正本用一般的圖片寫法 `![圖裡有什麼](img/檔名.png)`，在 GitHub 上直接看得到；還沒拍的先寫一行 `〔圖：檔名｜圖裡有什麼〕`。外掛自己的畫面由截圖工具照劇本產生，Obsidian 的畫面在裝了 Obsidian 的電腦上用腳本開示範 vault 拍，不用真的 vault（[規畫〈試做的結果〉](../plans/manual.md#試做的結果)）。畫面改了才重拍，檔名不變。
- **示範的內容自己寫**：不用出版社課本的內容、孩子的姓名與真實紀錄（D-003）。
