**任務段**：用外掛同一個 commit 的 `taskSection` 算，只改三處：

1. 拿掉點選填空的說明（`pickRules` 那幾行），只留任務資料的「點選填空：要／不要」一行；說明已經在核心〈比較與點選填空〉。
2. 拿掉已有目標的比對說明與兩個引言框的範例（`existingRules` 那一段），換成一行：`- 「學生已有的學習目標」每一項寫 \`ID 名稱｜出處｜第一題：……\`，第一題是那個目標現在的第一題（問答寫 \`題目 :: 答案\`，填空與排序寫整行），沒有題目的不寫；怎麼比對照規則〈和學生已有的目標比對〉。`（沒有已有目標時不加）
3. 英文也加「照規則交三段，標記照抄（`<<<全貌>>>`、`<<<架構>>>`、`<<<卡組>>>`）。」那一行；格式檢查要用三段的切法（`r3: true`）。

## 精簡清單組（D-229）

只換任務段「學生已有的學習目標」底下的清單與上面第 2 點那一行，其他和候選組一樣。

- 英文單字（名稱結尾是英翻中、中翻英、過去式、過去分詞、複數、比較級、最高級）：同一個字（名稱去掉結尾那一段，全形括號的意思留著）一行：`- someone｜英翻中 8q5s48、中翻英 jyr3ft｜pron. 某人｜國二上 L3`。第三欄是英翻中第一題的答案；這個字沒有英翻中時寫 `第一題：<題目> :: <答案>`（取這一行第一個目標的第一題）。第四欄是目標所在卡組的年級學期與單元（現行清單出處欄開頭的兩段，例如 `國二上 L3`）。
- 其他（文法、排序、比較與其他科）：`- <ID> <名稱>｜<年級學期與單元>｜<第一題>`，不寫「第一題：」；沒有題目的不寫第三欄。
- 第 2 點那一行改成：`- 「學生已有的學習目標」英文單字一個字一行：\`字｜方向或變化 ID、…｜英翻中的答案｜所在的單元\`（沒有英翻中的字寫第一題）；其他每一項 \`ID 名稱｜所在的單元｜第一題\`。怎麼比對照規則〈和學生已有的目標比對〉。`
