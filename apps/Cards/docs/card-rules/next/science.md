## 國中自然：每課一定要有

適用國中自然（生物、理化、地球科學），不限版本。下面七類逐項找，寫進全貌段的〈對照教材〉：

1. **定義的名詞**：正文用粗體、或寫成「……稱為……」「……叫做……」的名詞，各有一個目標，或在某一池裡有一題要學生說出它的意思；和相近的名詞一起出現時，照〈比較與分類〉。
2. **正文的因果與變化**：每個「為什麼」，以及每個寫出方向的變化（變大、變小、先升後降），照〈關係要說出方向〉。
3. **教材寫出、後面要用的數值**：常數、標準值（某種物質在某個條件下的值）與教材要學生記住的範圍：另立目標，或放進用到它的那一池。
4. **公式與單位**：每個公式的意義、符號與單位，以及教材的例題、習題用到的每一個求法，照〈公式與計算〉。
5. **實驗與活動**：課本的每個實驗、活動與示範，照〈實驗〉。
6. **圖表**：教材要學生讀出的關係，照〈讀圖表〉。
7. **課本列的學習目標與課本的提問**（例如「想想看」「動動腦」）：每一個都有目標或題目承接。

## 知識類型怎麼問

| 類型 | 問法 |
|---|---|
| 定義 | 「什麼是……」「用自己的話說明……」；答案寫 2～3 個關鍵詞，不要求逐字背課本 |
| 因果 | 「為什麼……」「如果……會怎樣？為什麼？」 |
| 變化的方向 | 「……增加時，……會怎樣變？」；答案寫出方向與條件 |
| 比較 | 「A 和 B 有什麼不同？」；答案寫教材列的那 2～3 點 |
| 構造與功能 | 「……有什麼功能？」；教材寫了構造為什麼長這樣的，問為什麼 |
| 順序 | 變化過程、構造的先後：「依序說出……」；實驗步驟只問有理由的那一步（〈實驗〉） |
| 公式與單位 | 公式的意義、符號代表什麼、單位，以及「已知……求……，怎麼列式」 |

## 關係要說出方向

教材寫了兩個量的關係、或在某個條件下的結果時，判準與答案都寫出方向和條件（「溫度升高時，……變大」）；只答「有關」「會影響」不算會。題目問「怎麼變」，不給方向讓學生選。教材寫「通常」「大多」的，答案也照寫；例外只在教材寫出時才出題。

## 公式與計算

- **公式用到的每個求法都要練到**：一個公式一個目標，判準寫「能用 <公式> 由其中兩個量求第三個」。池裡第一題問公式本身，再加教材的例題、習題用到的每一個求法各一題：「已知……和……，要求……，怎麼列式？」，答案寫算式與單位（照共用核心〈判準列了好幾項〉）。教材沒用到的變形不出，也不把每個求法拆成自己的目標。
  - 例：速率＝距離÷時間，教材的例題求了速率，也求了時間，池裡就有「已知距離和速率，要求時間，怎麼列式？ :: 時間＝**距離÷速率**」，不只有「寫出速率的公式」。
- **一題只做一步**：一題只列一個算式，或只做一次單位換算；要好幾步、或要真的算出數字的，列在架構的「需要其他練習」，寫出背後的觀念出在哪個目標（製作模組〈4. 進展〉）。
- **例題要先判斷的條件**（哪個量要算進去、哪個不算、這個情形能不能用這個公式）：照製作模組的〈例題的觀念〉另立目標或加題；考題常常就考這一步。
- 數值與單位照課本的寫法（符號、上標）；答案有單位的都寫單位。

## 實驗

課本的實驗、活動與示範，逐項找下面四件，教材寫出來的都在第 ① 層：

- **目的**：這個實驗要回答什麼問題。
- **變因**：操縱、控制、應變變因各是什麼；控制變因為什麼要保持相同。
- **關鍵步驟的理由**：為什麼要這樣做（先做哪一步、用什麼器材、要注意什麼），不這樣做會怎樣。只照順序背步驟的不出。
- **結果與結論**：看到什麼、能說明什麼；結果和結論分開問。

## 讀圖表

教材的圖表要學生讀出的關係在第 ① 層，不留到加深：判準寫「從圖上的什麼（斜率、趨勢、交點、最高點、兩條線的比較）判斷什麼」。能附圖就照共用核心〈圖〉附在題目那一行；不能附的，題目用文字寫出作答需要的軸、單位與數值。

## 比較與分類

- 教材的對照（兩個相近的量、兩種現象）與「判斷屬於哪一類」的分類（兩種變化、幾種物質），照共用核心〈比較與點選填空〉與〈判斷屬於固定幾類中的哪一類〉。只有兩類時，題目要學生說出歸類的依據（教材的分類標準），不出只答一類的題。
- 教材在別處講到的操作或現象，又寫了它屬於哪一類的，加進那一類的題目池，不只寫在那個操作的目標裡：學生要在沒想到分類的地方也做得出判斷。
- 生活例子只用觀念在教材範圍內的；同一個原理的不同例子同一池，一個例子一題。

## 寫給孩子

- 用課本的詞與符號；日常說法和課本不同時（例如「重量」和「質量」），題目和答案照課本。
- 題目寫出作答需要的數值、單位與條件，不只寫「如圖」。

## 交出前檢查（自然）

- [ ] 〈對照教材〉七類都逐項寫了；粗體與「稱為」的名詞都有題目考到
- [ ] 寫出方向的變化，判準和答案都有方向與條件
- [ ] 每個公式的池裡，教材用到的每個求法都有一題；多步計算都在「需要其他練習」，寫了觀念出在哪個目標
- [ ] 每個實驗的目的、變因、關鍵步驟的理由、結果與結論都找過
- [ ] 教材要讀圖的地方有題目讓學生從圖找出關係，沒有留到加深
- [ ] 只有兩類的分類題，答案有歸類的依據
- [ ] 數值答案都有單位，寫法照課本
