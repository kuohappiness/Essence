## 和「不做」比較（D-153）

- **不做會怎樣**：英文預設已經在產生 `… 文法`、`go 過去式`、`間接問句 排序` 的目標（翰林八上 L4、L5 試過），現在照填空或問答翻面自評：文法和變化形在腦中拼很容易以為自己拼對（D-066 的理由），紀錄也不算打字或排序的證據（D-193 第 13 點）；變化目標第一天就和原形一起出，孩子還不認得這個字就先練它的過去式；排序卡三句是三題填空，翻面看答案，練不到詞序。D-193 理由的三個缺口裡，「文法等考錯才補」與「不規則變化和原形綁在一起」要靠這次才補得上。
- **做的代價**：認法多兩種結尾、打字的條件從「中翻英」改成三種、第 2 步多一種提示、今天的份多一條開始條件、排序卡多一種版面（一句好幾格）與字鍵的大小寫與標點處理；都寫成測試。名稱結尾的詞可能和別科撞（「複數」在數學也有），所以新的兩種讀不成打字時照翻面出、只提示，不擋（§1-3）。

## 範圍

### 1. 認法（`src/core/deck/question-types.ts`、`parse.ts`、`types.ts`）

1. **結尾**：名稱最後一段（前面要有半形或全形空白，或右括號 `）`、`)`，和排序、比較卡的結尾相同）是：
   - `文法` → 文法目標；
   - `過去式`、`過去分詞`、`複數`、`比較級`、`最高級` → 變化目標。
   - 中翻英照舊；名稱讀得出點選填空的組（`borrow（borrow、lend） 文法`）時照點選填空，不打字。最上層直接寫題目（implicit）的目標不看結尾。
2. **打字的題目**：這兩種目標的問答題，答案照中翻英的 `typedAnswer` 讀（` | `、字數、不能有的字元都相同，[syntax §2-3](../docs/syntax.md#2-3-學習目標)），讀得成就打字，和中翻英同一套三步與紀錄。
3. **讀不成打字時**（答案多行、含中文、有連結等；或那一題是填空）：**那一題照翻面出，提示不擋**（`typed-answer-invalid`、`cloze-not-typed` 的 hint 版本，訊息寫「文法／變化的答案……，這一題照翻面出」），目標照常出題。中翻英照舊是錯誤。理由：中翻英的結尾只有英文會用，「文法」「複數」別科也可能拿來當名稱結尾（數學的複數），寫成錯誤會把那些目標停掉。AI 交的草稿照舊由 `check-syntax` 擋（§5）。
4. **原形與文法點**（第 2 步要用，存在 `Target` 上，不在複習時再拆名稱）：
   - 變化：名稱去掉結尾、再去掉最後一組全形括號（D-125，同 `baseForm`）：`go 過去式` → `go`；`lie（躺） 過去式` → `lie`。
   - 文法：名稱去掉結尾，取第一個左括號（全形或半形）前面那段：`現在完成式（從過去持續到現在） 文法` → `現在完成式`；沒有括號就是整段：`被動語態 文法` → `被動語態`。去掉成對的 `**`、前後空白；空的就沒有提示。
5. **變化的配對鍵**（§3 用）：名稱去掉結尾那一段，照 `pickKey` 的寫法正規化（去掉成對 `**`、`==`，全半形折成一樣，連續空白當一個，英文不分大小寫）；**有沒有括號**另記：`go 過去式` 是「`go`、任一個意思」，`light（輕的） 比較級` 是「`light（輕的）`、只這個意思」。

邊界例子（每一列都寫成測試）：

| 名稱 | 結果 |
|---|---|
| `go 過去式`、`go　過去式`（全形空白）、`light（輕的）比較級` | 變化 |
| `go過去式`、`過去式`（只有結尾） | 不是：結尾前沒有空白或右括號／沒有字 |
| `能說出 go 的 過去式` | 變化，原形 `能說出 go 的`：程式不判斷字是不是英文；答案含中文時照 §1-3 翻面 |
| `現在完成式（從過去持續到現在） 文法`、`動名詞(當主詞) 文法` | 文法，文法點 `現在完成式`、`動名詞` |
| `能在描述經驗時用現在完成式`（錯題補強的舊寫法） | 照舊翻面（english.md §5 A：用 ID 認，不改名） |
| `borrow（borrow、lend） 文法` | 點選填空（組優先） |
| `go 過去式 中翻英` | 中翻英（方向優先） |

### 2. 第 2 步的提示（`src/review/typed.ts`、`base-form.ts`、`ui/screens.tsx`）

1. 變化：提示原形，和某一個答案比對起來一樣時跳過（現在中翻英的規則）。
2. 文法：提示文法點。**題目已經給了**時跳過：題目文字去掉 `**`、`==`、`*` 之後，全半形折成一樣、不分大小寫，含有文法點這串字，就算給了（例如題目寫 `（現在完成式）I ＿＿ Tom since I was six. (know)`）。
3. 跳過時紀錄的 `retry` 寫 `not-needed`，和現在相同。[syntax §5](../docs/syntax.md#5-複習紀錄) 的 `retry` 定義從「原形提示」改成「原形或文法點提示」。
4. 畫面：「提示：」後面的字只有沒有中文時才標 `lang="en"`（文法點是中文）。

### 3. 變化目標的開始條件（`src/core/study/plan.ts`）

D-193 第 5 點、english.md §3〈開始〉。只改今天的份（`planToday`）：

1. 變化目標**還沒有紀錄**時，找同一篇卡組裡**配對得上的英翻中**：英翻中的 `pairKey` 照 §1-5 正規化後
   - 變化沒有括號：去掉最後一組全形括號後等於變化的鍵（`go 英翻中`、`go（走） 英翻中` 都算）；
   - 變化有括號：整個等於變化的鍵（`light（輕的） 英翻中` 才算，`light 英翻中` 不算）。
2. 配對得上的英翻中裡，**今天是候選的**（啟用、沒寫錯、沒暫停、有 ID、沒有重複、沒被濾網或讀不懂的紀錄停掉，和中翻英等英翻中用同一組條件）有任何一個「記得」（現有的 `remembered`：最後一次記住了或太簡單、今天沒到期），變化就照常出；一個都還沒記得就今天不出。
3. 一個候選的英翻中都沒有（沒有這個字的英翻中、或都停掉了），照常出：國二才開始用的孩子不會卡住（D-193 第 5 點）。
4. 變化目標有紀錄之後就不再看英翻中。不做「同一天到期只出一個」（那是兩個方向的規則，D-069）。
5. 全部卡的一輪、單篇練習、小考不加這條（中翻英在那裡也不等英翻中，[practice.ts](../src/core/study/practice.ts) 只排順序）。

邊界例子：`go 英翻中` 沒紀錄 → `go 過去式` 不出；記住了、明天到期 → 出；今天到期 → 不出（照 `remembered`）；`go 英翻中` 暫停 → 出；另一篇有 `go 英翻中`、這一篇沒有 → 出；只有 `go（走） 英翻中` 而且還沒記得 → `go 過去式`、`go（走） 過去式` 不出，`go（去） 過去式` 找不到配對、照常出（第 3 點）。

### 4. 英文的排序卡（`question-types.ts` 的 `readOrder`、`compose.ts`、`review/pick.ts`）

1. **認法**：名稱最後一段是 `排序`、沒有方向也沒有組。
   - **句子排序**（新）：每一題都是兩格以上的填空，每一題的空格裡都有拉丁字母；題數不限（english.md 每個目標先 3 句）。
   - **全詩**（照舊）：只有一題、兩格以上的填空、空格裡沒有拉丁字母。
   - 都不符合的照原題型（填空翻面），不提示，和現在相同。
2. **一張卡是一題**：照一般的出題輪替（D-028，`choosePrompt`）選一題，那一題的每一格是一格；一個目標、取最差的一格，紀錄照全詩順序卡（一行、`cell`、`pick`、`also`，[syntax §5](../docs/syntax.md#5-複習紀錄)）。
3. **字鍵**：每一格的文字是一個鍵，相同的各一個鍵；打亂的順序照全詩（`orderKeys`：和答案的順序不同、和上一次不同）。放過的鍵變淡、點了交換，照 D-204 第 3 點（`pick.ts` 已經這樣做，不用改）。
4. **文字相同的詞塊互換不算錯**：一格對不對比的是文字，不是哪一個鍵（`pick.ts` 已經這樣做，加測試釘住）。
5. **標點不洩漏**：每一格的文字結尾連續的標點（`. , ? ! ; :` 與全形的 `。，？！；：`）從鍵拿掉，接在那一格後面的文字前面，照樣顯示在句子裡。拿掉之後是空的就不是排序卡（照第 1 點的不符合）。
6. **句首大寫不洩漏**：一格「在句首」是指它前面的文字去掉空白與開引號、開括號後，什麼都沒有、或最後一個字是中文字、全形標點，或 `. ? ! :`。在句首的格，文字的第一個詞第一個字母是大寫、後面不是全部大寫（不是 `TV`、`USA`）、也不是 `I` 或 `I'` 開頭的，鍵上改成小寫（`Where` → `where`）。比對用改過的文字。畫面上放進句首那一格的字（作答時與對答案後）第一個字母顯示成大寫。人名放在句首會變成小寫的鍵：english.md §5 B 已經要求句首留在空格外，記進已知的限制。
7. **舊版**：不加 `需要版本`（同 D-204 第 6 點）；舊版照填空翻面出，現在的 `main` 也是。

邊界例子：`Do you know ==where== ==the bus stop== ==is==?` → 鍵 `where`、`the bus stop`、`is`，`?` 留在句尾；`==Where== ==does== ==he== ==live==?` → 鍵 `where`、`does`、`he`、`live`，第一格顯示 `Where`；`==I== ==am== ==not==` 句首 → 鍵 `I`；`I saw ==the== ==man== and ==the== ==dog==.` → 兩個 `the` 對調算對；`==lives.==` → 鍵 `lives`，`.` 接在後面；只有一題、空格是中文 → 全詩；兩題、空格是中文 → 不是排序卡。

### 5. AI 草稿的檢查（`experiments/t4/check-syntax.mjs`、`src/core/ai/check.ts`）

比解析嚴（[syntax §2-10](../docs/syntax.md#2-10-寫錯時)）：結尾是文法或變化種類、題目讀不成打字（§1-3 的兩種 hint），以及結尾是 `排序`、空格裡有拉丁字母卻不是排序卡的，算錯誤，退回重做。

### 6. 畫面與朗讀（`ui/PickCard.tsx`、`ui/Markdown.tsx`、`ui/rendered.ts`、`review/english.ts`）

1. **句子排序的版面**：整題一列，中文句子之後英文換行（現有的 `breakBeforeEnglish`），每個 `＿＿` 都是一格；字鍵是詞塊，照比較卡的「詞」排法（`keyColumns` 的 words）；空格的樣式照比較卡（D-182 第 8 點），不是全詩的「填了不留底線」。左邊一個打勾，照整題最差的一格；對答案後每一格照自己的對錯著色，同比較卡。
2. 對答案後，這一題底下的補充（詳解）與目標的共用補充（記憶錨點）接在句子下面，和翻面的背面一樣。
3. **朗讀**（D-186）：文法、變化的打字卡和中翻英一樣，答案出現時先念答案、再念把 `＿＿` 換成答案的句子；喇叭與英文的換行規則（`english`）也一樣。排序卡不朗讀（同全詩順序卡），記進 backlog。
