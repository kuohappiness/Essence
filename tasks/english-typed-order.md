## 和「不做」比較（D-153）

- **不做會怎樣**：英文預設已經在產生 `… 文法`、`go 過去式`、`間接問句 排序` 的目標（翰林八上 L4、L5 試過），現在照填空或問答翻面自評：文法和變化形在腦中拼很容易以為自己拼對（D-066 的理由），紀錄也不算打字或排序的證據（D-193 第 13 點）；變化目標第一天就和原形一起出，孩子還不認得這個字就先練它的過去式；排序卡三句是三題填空，翻面看答案，練不到詞序。D-193 理由的三個缺口裡，「文法等考錯才補」與「不規則變化和原形綁在一起」要靠這次才補得上。
- **做的代價**：認法多兩種結尾、打字的條件從「中翻英」改成三種、第 2 步多一種提示、今天的份多一條開始條件、排序卡多一種版面（一句好幾格）與句首、標點的處理；都寫成測試。名稱結尾的詞可能和別科撞（「複數」在數學也有），所以新的認法**只在科目是英文的卡組**（§1-1）。

## 範圍

### 1. 認法（`src/core/deck/question-types.ts`、`parse.ts`、`types.ts`）

1. **只在英文的卡組**：卡組屬性的 `科目` 是 `英文`；屬性沒寫科目時，用呼叫端給的科目（`parseDeck(text, { subject })`，AI 草稿檢查時給這次的科目）。別科、沒有科目的卡組照舊，文法、變化、句子排序都不認（格式查核 F1）。
2. **結尾**：名稱去掉成對的 `**` 之後，最後一段（前面要有半形或全形空白，或右括號 `）`、`)`，和排序、比較卡的結尾相同）是：
   - `文法` → 文法目標；
   - `過去式`、`過去分詞`、`複數`、`比較級`、`最高級` → 變化目標。
   - 中翻英、英翻中照舊（方向優先）；名稱讀得出點選填空的組（`borrow（borrow、lend） 文法`）時照點選填空，不打字。最上層直接寫題目（implicit）的目標不看結尾。
3. **打字的題目**：這兩種目標的問答題，答案照中翻英的 `typedAnswer` 讀（` | `、字數、不能有的字元都相同，[syntax §2-3](../docs/syntax.md#2-3-學習目標)），讀得成就打字，和中翻英同一套三步與紀錄。**讀不成打字是錯誤**（`typed-answer-invalid`，訊息開頭「文法與變化的答案」），目標停出，同中翻英；填空題照翻面出、只提示（`cloze-not-typed`），同中翻英。同一個目標裡打字與翻面的題可以混著。
4. **變化的字與意思**：名稱去掉結尾之後，**最後一組成對的括號**（全形或半形，左右可以不同）是意思，括號前面是字。
   - 字不能有中文（`能說出 go 的 過去式` 不是變化），字裡不能還有括號，括號不成對也不是變化（`go（去 過去式`、`go（v.）（去） 過去式`）。都不是時照原題型。
   - 第 2 步的提示是字（`lie（躺） 過去式` → `lie`；`**Go** 過去式` → `Go`）。
5. **變化的配對鍵**（§3 用）：名稱先去掉成對的 `**`、`==`（英翻中也一樣，L2 R7），再拆字與意思；字與意思各自照 `pickKey` 正規化（全半形折成一樣、連續空白當一個、英文不分大小寫），接成 `字(意思)`；括號前的空白不算。沒有括號的鍵只有字，另記「任一個意思」。
6. **文法點**：名稱去掉結尾、再去掉最後一組成對的括號（用法）：`現在完成式（從過去持續到現在） 文法` → `現在完成式`；`動名詞(當主詞) 文法` → `動名詞`；沒有括號是整段。剩下的是空的、或還有括號（`（當主詞） 文法`、`不定詞（to V）（當受詞） 文法`）時沒有提示。

邊界例子（每一列都寫成測試，`tests/english-typed-deck.test.ts`）：

| 名稱（英文卡組） | 結果 |
|---|---|
| `go 過去式`、`go　過去式`（全形空白）、`light（輕的）比較級`、`lie (躺) 過去式`、`**go 過去式**`、`give up 過去式` | 變化 |
| `go過去式`、`過去式`（只有結尾） | 不是：結尾前沒有空白或右括號／沒有字 |
| `能說出 go 的 過去式`、`go（去 過去式`、`go（v.）（去） 過去式` | 不是：字有中文／括號不成對／不只一組 |
| `現在完成式（從過去持續到現在） 文法`、`動名詞(當主詞) 文法` | 文法，文法點 `現在完成式`、`動名詞` |
| `能在描述經驗時用現在完成式`（錯題補強的舊寫法） | 照舊翻面（english.md §5 A：用 ID 認，不改名） |
| `borrow（borrow、lend） 文法` | 點選填空（組優先） |

| 數學卡組的 `能化簡 複數`、沒寫科目的 `go 過去式` | 照原題型 |

### 2. 第 2 步的提示（`src/review/typed.ts`、`base-form.ts`、`ui/screens.tsx`）

1. 變化：提示字（原形），和某一個答案比對起來一樣時跳過（現在中翻英的規則）。
2. 文法：提示文法點。**題目開頭已經用括號標了這個文法點**時跳過：題目去掉 `**`、`==` 與開頭的空白後，第一段是 `（文法點）` 或 `(文法點)`，括號裡照 `pickKey` 比對相同（例如 `（現在完成式）I ＿＿ Tom since I was six. (know)`）。題目其他地方提到同樣的字（「不要用現在完成式」）、或括號裡不是同一個（`（現在完成式的否定）`）不算（格式查核 F3）。
3. 跳過時紀錄的 `retry` 寫 `not-needed`，和現在相同。[syntax §5](../docs/syntax.md#5-複習紀錄) 的 `retry` 定義從「原形提示」改成「原形或文法點提示」。
4. 畫面：「提示：」後面的字只有沒有中文時才標 `lang="en"`（文法點是中文）。
5. 中翻英的原形（`baseForm`）改用 `pairKey`：方向前是全形空白（`light（輕的）　中翻英`）也拿得掉（格式查核 F2 順帶發現）。

### 3. 變化目標的開始條件（`src/core/study/plan.ts`）

D-193 第 5 點、english.md §3〈開始〉。只改今天的份（`planToday`）：

1. 變化目標**今天以前沒有紀錄**（任何紀錄都算，錯題本、練習的也算；在一天開始時決定）時，找同一篇卡組裡**配對得上的英翻中**：
   - 變化沒有括號：英翻中的字等於變化的字（`go 英翻中`、`go（走） 英翻中` 都算）；
   - 變化有括號：字和意思都相同（`light（輕的） 英翻中` 才算，`light 英翻中` 不算）。
2. 配對得上的英翻中裡，**今天是候選的**（啟用、沒寫錯、沒暫停、有 ID、沒有重複、沒被濾網或重要程度篩掉；不在考試範圍裡的也算）有任何一個「記得」（現有的 `remembered`：最後一次記住了或太簡單、今天沒到期），變化就照常出；一個都還沒記得就今天不出。
3. **紀錄讀不懂停掉的英翻中**也算配對，記不記得不知道，所以變化等它恢復（格式查核 F4）。
4. 一個配對的英翻中都沒有（沒有這個字的英翻中、或都暫停、篩掉了），照常出：國二才開始用的孩子不會卡住（D-193 第 5 點）。重複 ID 的英翻中被拿掉時也照常出（已知的限制：重複 ID 要家長先處理，D-157）。
5. 變化目標有紀錄之後就不再看英翻中。不做「同一天到期只出一個」（那是兩個方向的規則，D-069）。
6. 全部卡的一輪、單篇練習、小考不加這條（中翻英在那裡也不等英翻中，[practice.ts](../src/core/study/practice.ts) 只排順序）。

邊界例子（`tests/english-inflection-plan.test.ts`）：`go 英翻中` 沒紀錄 → `go 過去式` 不出；記住了、明天到期 → 出；今天到期 → 不出（照 `remembered`）；最後一次答錯 → 不出；暫停 → 出；紀錄讀不懂 → 不出；另一篇有 `go 英翻中`、這一篇沒有 → 出；只有 `go（走） 英翻中` 而且還沒記得 → `go 過去式`、`go（走） 過去式` 不出，`go（去） 過去式` 找不到配對、照常出；`Light(輕的) 英翻中` 配 `light（輕的） 比較級`；數學卡組不看。

### 4. 英文的句子排序（`question-types.ts` 的 `readSentence`、`compose.ts`、`review/pick.ts`）

1. **認法**：英文的卡組裡，名稱最後一段是 `排序`、名稱沒有 `全詩`、沒有方向也沒有組，每一題都是兩格以上的填空，每一格有字（不是空的、不是只有標點）；題數不限（english.md 每個目標先 3 句）。空格裡是不是英文不看（格式查核 F5）。
   - 英文卡組裡寫了 `全詩 排序` 的照全詩順序卡；別科的卡組照舊，`readOrder` 不變。
   - 都不符合的照原題型（填空翻面），不提示；AI 草稿另外擋（§5）。
2. **一張卡是一題**：照一般的出題輪替（D-028，`choosePrompt`）選一題，那一題的每一格是一格；一個目標、取最差的一格，紀錄照全詩順序卡（一行、`cell`、`pick`、`also`，[syntax §5](../docs/syntax.md#5-複習紀錄)）。
3. **字鍵**：每一格的文字是一個鍵，相同的各一個鍵；打亂的順序照全詩（`orderKeys`：和答案的順序不同、和上一次不同）。只有兩個不同的鍵時，和答案不同的排法只有一種，先避開答案、允許和上一次相同；全部相同的鍵沒辦法打亂（L2 其餘核對）。放過的鍵變淡、點了交換，照 D-204 第 3 點。
   - 詞塊是純文字：格裡成對的粗體、斜體記號（`**…**`、`*…*`、`__…__`、`_…_`）拿掉，鍵、句首大寫、比對與 `pick` 都照看得到的字；題目的指紋照原文（L2 R6）。拿掉之後還有 Markdown 的記號（未成對的 `*`、`_`，連結、程式碼、公式、跳脫、字元參照）時，這一題不是句子排序，照原題型（L2 第二輪：`A_B` 和 `AB` 不會變成同一個鍵）；AI 草稿算錯誤。
4. **文字相同的詞塊互換不算錯**：一格對不對比的是文字，不是哪一個鍵（`pick.ts` 已經這樣做，加測試釘住）。
5. **句末標點**：只看最後一格。它結尾的 `.`、`?`、`!`，在後面只剩空白與結束的引號、括號時，從鍵拿掉、接在後面照樣顯示；拿掉之後還有 `.` 的是縮寫（`the U.S.`），不拿。中間格的標點不動（`Yes,` 是一個詞塊）。english.md §5 B 要求 `==` 不包標點，這條只是容錯（格式查核 F6）。
6. **句首大寫**：程式不改鍵的大小寫，比對照原文。english.md §5 B 要求詞塊照句子中間的寫法（句首的字寫小寫，`I`、專有名詞照原樣）。**第一格**在英文句子開頭（前面看得到的字去掉空白與開引號後沒有字，或最後一個字是中文、全形標點；連結照顯示的字，L2 第二輪）時，畫面上放進那一格的字第一個字母顯示成大寫（作答時與對答案後）。英文句子中間的 `. ` 之後不猜。AI 草稿的句首那格大寫是提醒（§5）。
7. **舊版**：不加 `需要版本`（同 D-204 第 6 點；使用者決定，格式查核 F7）：舊版照填空翻面出，現在的 `main` 也是；紀錄寫的是新版的 `cell`、`pick`，舊版讀得懂、照它自己的方式排程。寫進 syntax 與發布說明。

邊界例子（`tests/english-order.test.ts`）：`Do you know ==where== ==the bus stop== ==is==?` → 鍵 `where`、`the bus stop`、`is`，`?` 留在句尾；`他住在哪裡？==where== ==does== ==he== ==live==?` → 第一格標句首，放進去顯示 `Where`；`It rains. ==where== ==do== …` → 不標；`==I== ==am== ==not==` → 鍵 `I`；`I saw ==the== ==man== and ==the== ==dog==.` → 兩個 `the` 對調算對；`我不知道他住在哪裡。I don't know ==where== ==he== ==lives.==` → 鍵 `lives`，`.` 接在後面；`==the U.S.==` → 不拿；`==Yes,== ==I== ==do==.` → `Yes,` 不拿；`I know ==where== ==?==` → 不是排序卡；英文卡組 `Twinkle 全詩 排序` → 全詩；國文卡組的 `… 排序` 照舊。

### 5. AI 草稿的檢查（`src/core/ai/check.ts`）

只在英文的草稿，比解析嚴（[syntax §2-10](../docs/syntax.md#2-10-寫錯時)），算錯誤、退回重做：

- 文法與變化：答案讀不成打字（解析已是錯誤）；填空題；好幾個答案字數不同（`typed-answer-words`）；題幹不是恰好一個 `＿＿`。
- 結尾是 `排序`、沒寫 `全詩`、不是句子排序的。
- 提醒：句子排序第一格在句首、開頭是大寫（不是 `I`、不是全大寫）的，`english-order-capital`。

### 6. 畫面與朗讀（`ui/PickCard.tsx`、`ui/Markdown.tsx`、`ui/rendered.ts`、`review/english.ts`）

1. **句子排序的版面**：整題一列，中文句子之後英文換行（現有的 `breakBeforeEnglish`；第一格就是英文句子的開頭時，在第一格前面換行，L2 R5），每一格在要渲染的文字裡用自己的記號（私用區的一個字，`slotMark`），渲染後照記號各放一格，題目本來的 `＿＿`、相鄰的兩格都不會搞混；找不到記號、或畫面上同一個記號不只一個的格放在句尾並記一行錯誤，題目裡會解成私用區字的字元參照（`&#57344;`）先拿掉（L2 R1 與第二輪）；字鍵是詞塊，照比較卡的「詞」排法（`keyColumns` 的 words）；空格的樣式照比較卡（D-182 第 8 點），不是全詩的「填了不留底線」。左邊一個打勾，照整題最差的一格；對答案後每一格照自己的對錯著色，同比較卡。
2. 對答案後，這一題底下的補充（詳解）與目標的共用補充（記憶錨點）接在句子下面，和翻面的背面一樣。
3. **朗讀**（D-186）：文法、變化的打字卡和中翻英一樣，答案出現時先念答案、再念把 `＿＿` 換成答案的句子；先拿掉粗體與螢光筆（和第 2 步認標籤相同），題目開頭與結尾的一組括號（文法標籤、給的原形或意思）不念，括號裡有 `＿＿` 的是句子本身照念，句子中間的括號照念；題目沒有 `＿＿` 時兩個入口都只念答案（L2 第二輪）；題目那一行的喇叭和自動朗讀用同一個句子（`typedSentence`，L2 R4）；喇叭與英文的換行規則（`english`）也一樣。排序卡不朗讀（同全詩順序卡），記進 backlog。
